## Description
## Description
Make Wangp usable for content creation without weakening its governed render pipeline. Operators need a simple typed brief input that becomes a validated, provenance-attributed run_film dry-run plan before any GPU work is authorized.

## Epic Outcomes
- The advertised continuation CLI is usable or fails loudly with actionable guidance.
- An operator can provide a JSON content brief plus character plates and receive a validated no-GPU run plan.
- Planning remains deterministic, repository-attributed, and Paivot-governed.
- No render/QC doctrine is bypassed.

## OUT OF SCOPE
- Live GPU rendering: belongs to an accepted render story after plan review.
- A graphical UI: this epic is CLI/API-first.
- Automatic model choice beyond existing deterministic routing.
- Weakening render, audio, identity, provenance, or QC gates.
