## Description
## USER INTENT
The operator needs to point a deterministic checker at any generated-artifact bundle produced by this programme and receive a fail-closed pass/fail verdict with the exact missing, blank, or mismatched field names. An incomplete, unauthorized, or hand-edited bundle must never let a Maestro-parity row become `verified`.

This story is buildable NOW, before any lane evidence exists. Implementation and tests use fixture bundles created in real temporary directories. Demonstrating the checker against one real bundle from every lane belongs to capstone WD-fay0, not this story.

## Canonical Contract
Produce `docs/maestro-parity-evidence-contract.md` as the single programme-wide definition of a `wangp-dspy.maestro-parity-evidence/v1` bundle. Every lane story must reference this document rather than duplicating the field list.

The contract must define these required fields once, with canonical identifiers, types, and fail-closed semantics:

- `operator_authorization`: verbatim authorization text, scope, timestamp, and approval identity.
- `command`: the exact executable command and arguments.
- `repository.commit`: repository commit and dirty-state identity.
- `model_provenance`: model identity, source, hash or immutable version, license, and applicable download approval.
- `reference_provenance`: every reference path, role, hash, and license.
- `queue_attempt`: durable queue/job identifier, admission state, exit status, and retry identity.
- `output.sha256`: hash of every emitted artifact.
- `media_metadata`: dimensions, duration, fps, audio properties, and image alpha mode where applicable.
- `objective_gate_results`: every declared objective gate, its inputs, threshold, measured value, and verdict.
- `reviewer_verdict`: explicit reviewer decision and its evidence links.

The checker CODE is the executable enforcement of this document, not a second authority. It must expose its canonical field list programmatically, and a test must fail whenever the document field list or the checker field list diverges.

## OUT OF SCOPE
- Generating lane media, contacting a GPU or remote host, downloading a model, or requiring any existing lane bundle.
- Repairing, normalizing, copying, or mutating a bundle being inspected.
- Changing queue admission, renderer policy, preflight, wiring, or any production runtime behavior.
- Replacing lane-specific provenance or QC work; this story supplies only the common contract and checker.

## DIFF BUDGET
- About 3 files and under 450 authored changed LOC: the canonical contract, one checker CLI/module, and focused integration tests.
- No generated lane media is part of this story.

## Boundary Map
PRODUCES:
- docs/maestro-parity-evidence-contract.md -> `wangp-dspy.maestro-parity-evidence/v1`
  spec: single authoritative field names, types, completeness rules, hash semantics, and media/gate requirements used by every parity lane.
- scripts/verify_maestro_parity.py -> `verify_bundle(bundle: Path) -> VerificationReport`
  event: read a bundle, validate every contract field and artifact hash, emit named diagnostics, and return a CLI pass/non-zero-fail result without writing to the bundle.
- tests/test_maestro_parity_evidence.py -> real temporary-directory checker integration
  event: prove success, every missing-field class, blank/mismatched fields, tampered output hash, missing authorization, read-only behavior, and contract/code divergence detection.

CONSUMES:
- (future lane bundles): datasets/runs/maestro-parity/<story-id>/ -> `wangp-dspy.maestro-parity-evidence/v1`
  source: checker-compatible lane bundles; none is required for this implementation because fixtures demonstrate the contract.
- (fixture inputs): pytest `tmp_path` fixture bundles -> real files and JSON records
  event: construct complete and deliberately incomplete/tampered bundles on disk without mocks.

## Story Acceptance Criteria
1. [State] Given a complete, authorized bundle whose recorded hashes match the artifact bytes on disk, the checker returns pass and exits zero.
2. [Unwanted] Given any missing, blank, or mismatched contract field, a bundle whose recorded artifact hash disagrees with the artifact on disk, or a bundle with no recorded operator authorization, the checker returns failure naming the exact field and exits non-zero.
3. [Unwanted] The checker never writes to, repairs, timestamps, normalizes, or otherwise mutates a bundle it inspects; every pass and failure case is read-only.
4. [State] The checker and its tests run in normal CI with no GPU, remote host, network, model download, queue admission, or lane artifact dependency.
5. [State] `docs/maestro-parity-evidence-contract.md` defines the required fields exactly once, and the divergence test fails if that document and the checker field list differ.
6. [State] `uv run --frozen --extra dev pytest -q --junitxml=/tmp/WD-651z-full.xml` exits 0 with parsed JUnit `errors=0` and `failures=0`; `uv run --frozen --extra dev wgp release verify` reports `release=ready` and `tag_created=false`.
7. [Unwanted] `services/jobs/queue.py`, `services/director/renderers/policy.py`, `services/director/wiring.py`, `services/jobs/preflight.py`, and `scripts/run_film.py` remain unchanged from accepted base `40f8c2b373dec1c84ca5a596c821b740934af6fb`.
