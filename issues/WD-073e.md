## Description
## Context (Embedded)
`scripts/run_film.py --help` advertises:

```text
--continuation  strict six-cut Ref2VA continuation (requires turn wavs)
```

But the CLI parser exposes no ordered audio-path or duration arguments. Calling `run_film(..., continuation_mode=True)$ programmatically requires `audio_paths`; leaving them None raises. Therefore the advertised CLI flag cannot complete a strict continuation run without an undocumented Python call.

## USER INTENT
An operator should be able to run strict continuation from the documented command line by supplying ordered turn WAVs, or receive an actionable parser error before planning.

## OUT OF SCOPE
- Generating voice audio: VibeVoice supply remains separate.
- Changing chain/render semantics.
- Adding a new queue mode.

## DIFF BUDGET
- ~3 files, under 220 changed LOC.

## Boundary Map
PRODUCES:
- scripts/run_film.py -> repeatable --audio PATH arguments
- scripts/run_film.py -> optional repeatable --duration-s NUMBER arguments
- scripts/run_film.py -> continuation CLI validation that rejects missing audio before side effects
- tests/test_run_film_cli.py -> parser and programmatic bridge coverage

CONSUMES:
- (existing): scripts/run_film.py -> run_film(script_file, plates_dir, characters, audio_paths, durations, continuation_mode, dry_run)

## Acceptance Criteria
1. The documented CLI accepts an ordered list of turn WAV paths.
2. It optionally accepts one duration per turn.
3. `--continuation` without audio fails with an actionable message and no host/GPU calls.
4. Audio count mismatch with script rows fails before planning.
5. Duration count mismatch or nonpositive duration fails before planning.
6. Valid arguments reach the existing `run_film` continuation path without changing job semantics.
7. Existing non-continuation CLI behavior remains compatible.

## Testing Requirements
- Unit: argparse behavior and validation.
- Integration: use the existing run_film dry-run seam and injected fixtures; no GPU, SSH, network, or live render.
- Commands:
  - uv run --frozen --extra dev pytest -q tests/test_run_film_cli.py
  - uv run --frozen --extra dev pytest -q tests/test_run_film_cli.py tests/test_director_wiring.py
