## Description
## Context (Embedded)

Discovered during accepted `WD-8l2f` at main `0ba2773`.

A fresh story worktree could not run the LF003/AV calibration evidence suites
because required fixture bytes existed only as ignored/untracked files in the
primary checkout. The worker had to copy them temporarily and rebase paths in
a copied jobs database, then remove the temporary files. That makes the stated
test commands non-reproducible from Git.

## Required fixtures reported missing

```text
assets/acceptance/lf003-v3/anchor.png
assets/acceptance/lf003-v3/face_rho.png
assets/acceptance/lf003-v3/face_tess.png
datasets/lf003-two-cut-vibevoice-20260917.jobs.db
datasets/runs/pull/acceptance/worker-a08dc195c192/render-0001/remux.mp4
datasets/runs/pull/acceptance/worker-0646f3fdb158/render-0004/remux.mp4
datasets/runs/pull/acceptance/worker-94129b34bdd8/render-0000/remux.mp4
datasets/runs/pull/acceptance/worker-4e52f8dc1fc7/render-0000/remux.mp4
```

Approximate combined size is under 8 MiB.

The asset directory is excluded by local `.git/info/exclude`; the database is
ignored by `datasets/*.db`; and render media are ignored under
`datasets/runs/pull/`.

## USER INTENT

A fresh Git clone or story worktree must be able to run the declared LF003 and
SyncNet evidence tests without copying private files from the primary checkout.

## Goal

Make the required test evidence portable and path-stable in Git, with exact
hashes and no test skips. Tests must pass from a fresh worktree without the
primary checkout.

## Design options

Choose the smallest durable option:

1. commit exact fixture bytes at the paths tests currently expect and make any
   jobs-database path references portable; or
2. commit them under a versioned test-fixture directory and update tests through
   a shared fixture-root helper.

Do not weaken tests or point them at the primary checkout.

## OUT OF SCOPE

- Changing production vision, SyncNet, renderer, or QC behavior.
- Re-rendering media.
- Adding all ignored datasets or pull runs.
- Adding credentials, remote-only paths, or unhashable artifacts.
- Skipping evidence tests when fixtures are absent.

## DIFF BUDGET

- ~10 text files, under 400 changed LOC, plus the enumerated fixture bytes.

## Boundary Map

PRODUCES:
- portable Git-tracked fixture files listed above (or equivalent test-fixture
  paths plus a fixture-root helper).
- test changes that load the fixtures without depending on the primary checkout.
- provenance manifest recording each fixture path and SHA-256.

CONSUMES:
- existing tests:
  `tests/test_av_sync_gate.py`,
  `tests/test_lf003_fullgate_bundle.py`,
  `tests/test_lf003_strict_vibevoice_bundle.py`,
  `tests/test_lf003_vibevoice_bundle.py`

## Acceptance Criteria

1. Every fixture needed by the declared LF003/AV tests is represented in Git or
   by a deterministic tracked fixture source.
2. A fresh worktree contains the required bytes without copying from the
   primary checkout.
3. Any jobs-database path dependence is made portable or is rebased by test
   setup deterministically.
4. The exact test commands pass in a fresh worktree with zero skipped tests.
5. A fixture manifest records path, byte size, and SHA-256 for every required
   artifact.
6. Test code fails closed if a fixture is missing or its hash changes.
7. No production behavior changes.
8. `git diff --check` passes.

## Testing Requirements

- Fresh-worktree integration is mandatory.
- Run the LF003/AV targeted suites from a newly created worktree.
- Run `git diff --check`.
- Record the fresh-worktree commit SHA.
