## Description
## Description
Install an automatic, local-only Codex skill suggestion router for user prompts. The router indexes installed SKILL.md files, ranks them against each incoming prompt, and injects compact advisory context through the native UserPromptSubmit hook.

## Context
The operator has 334+ local skills and wants automatic selection equivalent to the useful part of SkillRanker without copying its implementation. Codex supports UserPromptSubmit hooks that return hookSpecificOutput.additionalContext. The MVP must remain deterministic and offline.

## Acceptance Criteria
1. A local indexer scans the configured Codex, agent, system, and plugin skill roots and builds a valid SQLite FTS5 index with mode 0600.
2. The UserPromptSubmit hook consumes the documented stdin JSON shape and returns valid hookSpecificOutput.additionalContext for relevant prompts.
3. Short/conversational/unrelated prompts return an empty JSON object rather than forcing a skill suggestion.
4. Malformed stdin, missing database, SQLite errors, or configuration errors fail open with exit 0 and empty JSON output.
5. Telemetry records prompt hash, timing, decision, and candidate names/paths only; it never records raw prompt text.
6. The hook is registered in /Users/speed/.codex/hooks.json while preserving all existing hooks, and a pre-change backup exists.
7. Automated tests exercise indexing, relevant suggestions, abstention, malformed input, missing database, and hook-output shape using /usr/bin/python3.
8. Relevant-hook latency remains under 500 milliseconds on the local index in the measured test run.

## Design
- index_skills.py parses bounded SKILL.md front matter/body text into FTS5 fields.
- hook.py tokenizes the prompt, removes stopwords, applies modest domain synonyms, ranks FTS5 results, and gates low-confidence matches.
- Suggestions contain skill name, path, score, and matched terms only.
- No network calls, Jev calls, skill execution, or prompt persistence.
- The hook outputs compact advisory context instructing Codex to read the complete SKILL.md only if relevant.

## OUT OF SCOPE
- Jev reranking.
- Semantic embeddings.
- Automatic skill execution.
- Any code copied from or derived from SkillRanker.
