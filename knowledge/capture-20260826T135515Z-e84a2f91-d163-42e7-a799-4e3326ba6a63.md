   run_cycle.py (GLM briefs+profile -> SshHost render -> record) ->
   gpu_seq start-critic -> health poll (<=150s) -> run_qc.py -> record

3. Checkpoint strategy: per-cycle record written immediately after render
   (before QC) — crash loses at most one QC leg, never a render. Resume
   via --skip-done (first-60-char match). No state outside records.
4. Evidence & gates: per record videos[] non-empty, qc.score >= 4.5,
   evidence[] trail present, ffprobe frame counts within tolerance.
   Luna samples 3 records for RED genuineness. GLM reviews step-1 diff.
   Operator approves merge + archive.
