# Gate-Array Pattern (extracted technique 1/4)

Single pure function `gateReport(artifact, ctx)` computes ALL quality checks at once, returning a flat array of `{ id, label, ok, detail }` gate objects; validate, reports, CLI logs, and exports all consume that one array. Collect-then-report (failures accumulate in a `bad` map keyed by gate id; all `add()` calls in one final block). Optional inputs skip LOUDLY (`ok: true` + visible skip detail, never throw, never silent-pass). Deterministic and zero-model (string/number logic over artifact JSON; whole battery runs in a selftest). Computed thresholds live in the label so the report can never lie about the rule. Every gate needs a break-case test.
