Live 3090 smoke render (WD-t6i7) found three wgp adapter gaps: (1) force_fps must be a STRING (get_computed_fps len()s it) - fixed 9a3b1ef; (2) --output-dir is ignored by wgp - output lands in Wan2GP/outputs/ regardless; (3) wgp exits 0 even when a task is skipped (e.g. OOM) - empty readback must be treated as failure. Also: local vLLM critic needs OPENAI_API_KEY env (litellm quirk), and the adapter assumes renderer-locality which breaks when driving a remote GPU.
