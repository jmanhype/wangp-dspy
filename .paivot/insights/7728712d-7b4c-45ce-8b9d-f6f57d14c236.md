modeled concat seam loss as ~2 frames per seam. Cumulative live
measurements: n=3 diff 4 (~2.0/seam), n=4 diff 8 (~2.67/seam) — the
linear-2 tolerance fired on a GOOD cycle-4 render (420f vs 428f,
diff 8 == tolerance(4)). Per-seam ceiling is now MEASURED_SEAM_CEILING=3
(tolerance(n) = 2 + 3*(n-1)); recalibrate at an n>=6 data point. The
n>=6 recalibration MUST capture PER-SEAM loss (total_diff / (n-1)) at
each n so the loss curve can be fitted rather than endpoint-bounded.
